Kebijakan Privasi Rak Buku

Rak Buku adalah aplikasi pribadi untuk membaca file PDF.

Akses ke Google Drive

Aplikasi hanya meminta izin drive.file. Dengan izin ini aplikasi hanya bisa membuka file yang dibuatnya sendiri, bukan isi Drive yang lain. Izin ini dipakai untuk menyimpan buku yang kamu tambahkan dan data baca (judul, kategori, sampul, posisi terakhir, dan bookmark beserta catatannya) di folder "Rak Buku" di Drive-mu.

Data di perangkat

Salinan buku, data baca, dan kunci login terenkripsi disimpan di perangkatmu supaya aplikasi bisa dipakai offline.

Server login

Server kecil di Cloudflare meneruskan proses login ke Google dan mengenkripsi token login. Server ini tidak menyimpan token dan tidak menerima isi buku atau data bacamu.

Pihak lain

Data tidak dijual atau dibagikan. Tidak ada iklan dan pelacak. Google (Drive dan login), GitHub (hosting halaman), dan Cloudflare (server login) memproses permintaan sesuai kebijakan mereka masing-masing.

Menghapus data

Cabut akses aplikasi di myaccount.google.com/permissions, hapus folder "Rak Buku" di Drive, lalu hapus data situs aplikasi di perangkatmu.
